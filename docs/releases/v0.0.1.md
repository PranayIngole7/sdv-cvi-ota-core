# v0.0.1 — Project Foundation

## Purpose

Establish the repository, application bootstrap, development conventions,
and automated build verification for the Connected Vehicle Intelligence
and OTA Platform.

## Included

- Java 25 and Spring Boot application bootstrap.
- Maven Wrapper pinned to Maven 3.10.0.
- Spring MVC and Actuator dependencies.
- Local development server configuration using port 18081.
- Health endpoint at `/actuator/health`.
- Architecture overview and development workflow documentation.
- Local environment and port allocation documentation.
- Automated application-context and health-endpoint integration tests.
- GitHub Actions workflow that runs `./mvnw clean verify` on pushes
  and pull requests targeting `main`.

## Acceptance criteria

- [x] Application starts successfully.
- [x] Health endpoint returns HTTP 200 and reports `UP`.
- [x] Maven clean verification completes successfully.
- [x] Automated tests pass without failures or errors.
- [x] GitHub Actions build-and-test workflow passes.
- [x] Changes are committed and synchronized with `origin/main`.
- [x] No generated build output or local secrets are committed.

## Limitations

This release is a project foundation, not a functional connected-vehicle
or OTA platform.

It does not yet include vehicle registration, a database integration,
vehicle telemetry, MQTT, Kafka, OTA package management, vehicle software
updates, authentication, or AI-based diagnostics.

The health endpoint reports application health; it does not establish
vehicle connectivity or OTA readiness.

## Next milestone

v0.1.0 — Vehicle Management.
